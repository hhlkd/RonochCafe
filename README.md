//RonochCoffee 
RonochCoffee is a simple coffee management application that demonstrates user authentication and data handling using a mock backend API. The app allows users to register, log in, and perform CRUD operations on coffee-related data stored on [Mockapi.io](https://mockapi.io/).


//Features 

- **User Authentication**: Register a new account or log in with existing credentials.
- **Mock Backend**: All data is persisted via Mockapi.io, simulating a real REST API.
- **Coffee Management**: Add, view, update, and delete coffee items (or orders, depending on your assignment).
- **Cross-Platform**: Runs on both Android and iOS (and can be adapted for web/desktop).
// Prerequisites 
Before running the application, ensure you have the following installed:

- [Flutter SDK](https://flutter.dev/docs/get-started/install) (stable channel)
- [Dart SDK](https://dart.dev/get-dart) (included with Flutter)
- An IDE such as [Android Studio](https://developer.android.com/studio) or
 [Visual Studio   Code](https://code.visualstudio.com/) with Flutter plugins
- An internet connection to communicate with Mockapi.io
